# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique ideas and not people, and help newcomers. Harassment and personal attacks are not accepted.

Report unacceptable behavior privately through the repository's **Security** tab (Report a vulnerability) or to the maintainer, Ciro Cesar Maciel, through [ciromaciel.click](https://ciromaciel.click/?ref=oss-ccm-stack). Reports are handled confidentially.
