# The CCM Stack course

**Coding agents that follow the rules.** By Ciro Cesar Maciel.

Each lesson takes one real mistake that coding agents make, states the rule that prevents it, and installs the hook or skill that enforces it. Every lesson has the same five parts:

1. **The mistake:** a real failure, in a few lines.
2. **The rule:** one sentence.
3. **Make it stick:** the hook or skill that enforces it, and how.
4. **Try it:** make the mistake on purpose and watch it get refused or fixed.
5. **Checkpoint:** how you know you learned it.

You finish each lesson with something working on your own machine: macOS, Linux or Windows.
