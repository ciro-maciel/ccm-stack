# 02 · Start from the person

**Module 1 · Work** · 15 minutes · [Previous](01-hear-when-its-done.md) · [Next: Write like a person](03-write-like-a-person.md) · Skill: [`intent`](../skills/intent/SKILL.md)

## The mistake

The agent writes a landing page that opens with "Welcome to our innovative platform". A visitor arriving from a search, worried about one specific problem, reads three paragraphs about the company and leaves. Every sentence was correct; none was for them.

## The rule

Every piece starts from the person who meets it: who arrives and in what state, what they want and do not say, what blocks them, what they leave with, and the one next step. Persuade only with true facts.

## Make it stick

The `intent` skill makes the agent answer those five questions before writing, then reread the draft as that person and fix every check that fails: recognition, value first, proof, honesty, one next step, the reader's words.

It applies to code too. An error message, a function name and a README each have a reader.

## Try it

Ask your agent:

```
Use the intent skill to rewrite the first screen of our README for a developer
who found this repo from a search and has two minutes.
```

Compare the opening sentence before and after.

## Checkpoint

For anything you ship this week, you can name its reader, the state they arrive in, and the one thing they should do next.
